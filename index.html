MiM Selective XRay — Ver1.0

BOOTHの商品ページ / Get it on BOOTH

使い方 / User Guide — PC版アバター向け

できること / Behavior

指定した表面越しに貫通対象とその内部のオブジェクトを表示し、VRCのExpressionsメニューでON/OFFできます。OFFは通常の遮蔽に戻ります。メッシュそのものを消すスイッチではありません。

Show a window through selected surfaces. OFF restores ordinary occlusion; it does not disable the mesh. Excluded surfaces drawn afterward can still hide the contents.

上図は設定の概念図です。実際のUnity画面ではありません。

必要なもの / Requirements

Unity 2022.3 Built-in Render Pipeline、VRChat Avatars SDK、Modular Avatar、lilToon。検証環境のlilToonは2.3.4、Modular Avatarは1.18.7です。これらは同梱しません。

PC avatars only. Quest/Android custom shader support, URP/HDRP, arbitrary third-party material conversion and full transparent window materials are not supported.

導入 / Setup

  1. 依存パッケージを導入し、本パッケージをインポートします。
  2. MiM → Selective XRay を開き、シーン上のアバターを指定します。
  3. 「貫通対象」に、他の表面越しに表示したいオブジェクトのRendererを指定します。lilToonの不透明マテリアルが対象です。
  4. 「透過対象」に、貫通対象を隠している表面のRendererを指定します。遮蔽を残したいRendererは含めません。階層や追従先による自動選択は行いません。
  5. 「対象の内部に見せるもの」に、同じ範囲で表示したい追加のRendererを指定します。空欄でも使用できます。貫通対象の投影範囲からはみ出す部分には効果が及びません。
  6. 「メニュー設定」で初期状態と記憶の有無を選び、「複製してON/OFFメニューを作成」を押します。
  7. シーンを保存し、VRCで XRay ON/OFF を確認します。ONにすると貫通表示が有効になり、OFFにすると通常の遮蔽に戻ります。

Assign the avatar, one opaque window renderer, selected occluding surfaces, and optional interior renderers. Press Duplicate and create ON/OFF menu, save the scene, then test XRay ON/OFF in VRChat.

安全な編集・取り消し / Changes and removal

元マテリアル、既存FX、既存メニューは直接編集しません。専用の複製マテリアル、ON/OFFアニメーション、FX追加レイヤー、メニューを Assets/MiM/SelectiveXRayData/Generated 配下に作成します。使用中の設定が入っているため、このフォルダーは削除しないでください。シーンには MiM Selective XRay を追加します。

直後の取り消しはUnityのUndoを使用します。後日外す場合はAssets/MiM/SelectiveXRayData/Generated/Setup* 内の OriginalMaterials.txt を参照して各Rendererの元マテリアルを戻し、MiM Selective XRay オブジェクトを削除します。再導入は旧設定を外してから行います。生成物は上書きせず新しいフォルダーになります。

Your generated settings are stored in Assets/MiM/SelectiveXRayData/Generated. Keep this folder while your avatar uses these settings. Undo immediately after setup, or restore materials using OriginalMaterials.txt and remove the generated scene object. Remove the old setup before reinstalling. Other animations that replace these materials or animate the same property must be updated separately.

表示の条件 / Rendering limitations

描画順は透過対象1980、貫通対象1981、内部1982、切断面1983です。遮蔽を残す対象は2000以降を想定します。特殊な低い描画順、深度を書かない透明物、複数の貫通窓が重なった構成では意図した結果を保証しません。貫通対象には、内部を表示したい範囲を覆う不透明な奥側の面が必要です。単なる輪郭だけでは、その内側全体に効果は及びません。追加するRendererも個別に指定してください。

Use one opaque target with a rear surface covering the area where its contents should appear. A border alone does not reveal the whole area inside it. Overlapping XRay targets, transparent surfaces without depth writing, and unusual render queues may display incorrectly.

更新情報 / Updates

ツールを開くと、Unityの起動中に一度、更新情報を自動で確認します。「更新を確認」から手動でも確認できます。新しいバージョンがあると、バージョンと変更内容が表示されます。「更新ページを開く」から入手してください。自動でファイルを上書きすることはありません。

The tool checks for updates once per Unity session. Use Check for updates to check again. When a newer version is available, review its changes and open the update page. Files are never installed automatically.
